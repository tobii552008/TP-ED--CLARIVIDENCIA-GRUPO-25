## 🚀 Descripción del Proyecto
**Clarividencia - Game Advisor** es una aplicación diseñada para gestionar y recomendar videojuegos utilizando estructuras de datos avanzadas en Python, permitiendo realizar búsquedas eficientes, análisis de tiempos y modelado de redes de afinidad[cite: 1].

---

## 🧩 Estructuras de Datos Implementadas
* **Árbol Binario de Búsqueda (BST):** Utilizado para el núcleo de almacenamiento y consultas rápidas de los títulos[cite: 1].
* **Grafos y Recorridos (BFS / DFS):** Módulo incorporado para modelar relaciones de similitud entre franquicias y caminos de recomendación[cite: 1].
