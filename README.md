## 🚀 Descripción del Proyecto
**Clarividencia - Game Advisor** es una aplicación diseñada para gestionar y recomendar videojuegos utilizando estructuras de datos avanzadas en Python, permitiendo realizar búsquedas eficientes, análisis de tiempos y modelado de redes de afinidad.

---

## 🧩 Estructuras de Datos Implementadas
* **Árbol Binario de Búsqueda (BST):** Utilizado para el núcleo de almacenamiento y consultas rápidas de los títulos.
* **Grafos y Recorridos (BFS / DFS):** Módulo incorporado para modelar relaciones de similitud entre franquicias y caminos de recomendación.

---

## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Python
* **Entorno:** GitHub Codespaces / VS Code
* **Almacenamiento:** Archivos JSON (`videojuegos.json`)
